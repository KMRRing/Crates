How to play

  1. Join the numbers in pairs. Drag from a number to draw a path; paths can't cross, share a hex or pass through another number.
  2. A path runs from the number you draw it from: the value starts as that number, every operation on the way changes it in turn (+, −, ×, ÷; values can become fractions, like 5 ÷ 4 = 1¼), and it has to arrive exactly at the other number. Which end to start from is yours to work out.
  3. Use every operation exactly once. Blank hexes are optional.

On Easy and Medium the value runs along the path as you draw, and a finished path shows whether it adds up. On Hard you work the values out yourself, and paths are only marked once every number is joined. A clue shows two numbers that belong together. To remove a path, tap either of its numbers.
