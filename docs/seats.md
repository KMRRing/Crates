# Seats
The card, dice and board games for a few seats round one table (October 2026: Liar's dice, Big Two, Dou Dizhu, Meld, Pegs, the trump games, dominoes, backgammon, Quest's hidden roles, and Cartel): each seat is a person or a computer player, and one runner, `seats.js`, plays any of them solo or at a table without the game knowing which. Solo, you sit in seat 0 and the computer players in the rest, on this device, with no connection needed; the game is kept as it changes (`<game>:game`), so a reload, another of your devices or a partner watching sees it as it stands. Invite players (the game's menu) opens a party with the game chosen (README, Party). A friend who joins mid-game sits down in the lowest free seat, which is a computer player's, and takes it over, hand and all; one who leaves gives it back to the computer, and one whose phone has been away for half a minute is played for until it's back, so nobody's sleeping phone holds up the table. Back to the party (the menu) takes every phone back to the lobby; each phone's solo game stays as it was.

A game is a module of pure functions (`deal`, `toMove`, `act`, `bot`, `over`; CLAUDE.md, "Tables"; `tests/seats.mjs` shows how to test one). The traps:
- Every move's randomness comes from the game's seed and the move's number, so a move worked out twice, as a transaction may be on a fresher copy, comes out the same.
- `restore` makes a state read back from the database whole again: the database keeps no empty lists.
- Every move is refused out of turn except those the game names in `anytime` (Meld's and Pegs' "next", on to the next hand).
- The device that runs the table (the host's, or the next in line) makes the computer players' moves, each a short while after the last so the people can follow it (a game can set that by the step: Quest's secret votes go in at once), and checks the table hasn't moved on meanwhile; a person's move is checked on their phone and again in the transaction.
- A page may make a move as it draws (a choice given before its turn, sent the moment it comes, as Banquet's throws and Quest's votes are): the runner must look at the table afresh before setting the next computer player going. Until October 2026 it went on with the view it had drawn, in which it was still the person's turn, and cancelled the move the person's own move had just set going, so the table stood still.
