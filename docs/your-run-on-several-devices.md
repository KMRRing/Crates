# Your run on several devices
Menu → Your other devices → Sync this run. The run gets an 8-letter code and a link; open the link on your other device (or type the code into Join there) and both devices follow the same run: the board you're on, your history, settings and learning cards. "Stop syncing on this device" keeps a local copy and lets go of the run.

Traps: a device that was left open with old progress catches up instead of overwriting newer progress. Each change carries the size of the word bank it was made with, so a device still on an older version of the app reloads itself onto the new one instead of dealing boards of its own (it couldn't read boards that use newer words). A device that is only following, untouched, doesn't run the clock or write anything.
