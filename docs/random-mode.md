# Random mode

A game at random, and when its round is over, straight on to the next (27 October 2026, Korbi: "add a "random" option to almanac that just takes a game (user can select which ones can appear) and every time a round is over, goes straight to the next one"). It's a way to play, not a game, so it isn't a tile: in the banner under the games screen's head (Deck, Random and Choose, a third each), the plate ⤮ Random opens one of the games chosen, and Choose opens the sheet, Random's side of it: every game random mode can deal, by the games screen's sections, each a tick box (menu.js's `ticks`), every one ticked at first. The choice is this device's own (`suite:random`, which never syncs: the phone and the iPad may want different games), kept as the games taken out, so a game added later comes in, as every game does at first. With nothing ticked, Random can't start.

While random mode plays a game, the game's title wears RANDOM beside its name (in the room the header has left, so it never moves the header's buttons), and its menu opens on a Random part, Next game and Stop (random mode ends, this game stays). The moment the round's result is final, a banner over the page names the next game and counts three seconds, then opens it; Stay ends random mode and leaves you where you are, the result in front of you. The countdown stands still while the page is out of sight or you've opened the games screen, a menu or the rules, and goes on when you're back; a result the game itself put up in such a dialog doesn't hold it. The next game is any of those chosen but the one just played, unless it's the only one, and it opens as its tile does: on today's daily while that's still to play.

Traps:
- A run of random mode is the session's (`suite:random-run`): closing the app ends it, and so does opening any other page yourself; the same game reloading (an update, a sync) plays on. It's solo only: never in a partner's watching frame, a duo match, a table, a party or an offline party, and a page that sits down at a table without reloading drops it.
- A round only drawn again as it was left (a finished board reopened) isn't one played: random mode waits for a tap or a key on the page before it counts one.
- A game must count its result the moment it's final, not when its summary opens (as the dailies do, README, The games screen's figures), so leaving on the banner loses nothing.
- Never import `random.js` from a module a Node test loads (`random-core.js` is the pure side).

**A new game hooks in** in `random-core.js`: `ROUNDS` with what its round is, or `LEFT_OUT` with why; `tests/random.mjs` fails until it is one or the other, and checks that every game dealt calls `roundOver` from its own files and names itself. A game says its round is over with `roundOver(id)` (its id on the games screen) from its own end-of-round code, after counting it; a game on `seats.js` gives every view to `seatRounds(id, steps)`, which counts the game's end and, where it's dealt hand by hand, the steps that end a hand, only as they change. A change to either module runs every test (`tools/pick-tests.mjs`), since every game loads them.

What counts as a round is each game's own, the natural unit you'd stop at (`ROUNDS` has each): a puzzle solved or given up, a hand or a deal settled, a run's last answer, an idle game's game over after its last move has played out. The exceptions:
- Nonogram's round waits for the picture's name when naming is on; Yield, whose puzzles have no end of their own, ends at Supergiant (70% of the puzzle's points) or when the puzzle is over.
- A deal thrown in or passed out and dealt again isn't a round (Big Two, Dou Dizhu, Cribbage, Contract bridge); Avalanche's lesson day isn't one; Topple in Levels is the level; Slipway is a part carved to a star; Courier is a run over (the hearts gone).
- A puzzle rush (Chess's page of its own, or a rush in Mahjong, Guandan, Xiangqi or on a sheet) is a mode of its game and ends no round.
- A game left mid-match is there as it was when random mode comes back to it.

Left out: Party and its games, Cue and Company, made for people round a table; Almanac and Ledger, the knowledge base and the record of how you learn, not games; and the whole Appendix (3 November 2026, Korbi: it stays out of Random and of Start a game over): the casino games, Blend, Refinery, Guilloché, Timegrapher and Banquet (4 November 2026); those that called `roundOver` still do, and it does nothing. Deck, the review of every game's misses, has no tile and so isn't in the list: it deals only what's due, and often has nothing to play.
