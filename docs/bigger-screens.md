# Bigger screens

Codex is drawn for a phone held upright, and a phone must look exactly as it did before bigger screens were filled (October 2026: every page, and every game a little way into play, compared pixel for pixel at three phone sizes in every theme by day and night). A bigger screen is filled in two ways (`style.css`, "Bigger screens"):

- **A tablet held upright draws the phone's layout larger.** Sizes are in rem (the root's font size, 16px on a phone), and on an upright tablet the root grows until the screen holds the layout as a large phone does, 35rem across and 50rem down. So a size that should grow is in rem; borders, radii, strokes, shadows and hairlines stay px, and so does text inside an SVG drawn to a viewBox, which grows with its drawing already. `tests/wide.mjs` fails on any other size of 3px or more in px (n px is n/16 rem, the same on a phone).
- **Held sideways** (wider than tall and at least 700px across: a tablet, a computer's window, a phone turned over), each game puts its parts beside its board: header across the top, the board, map or picture on the left with all the height, and the game's information and buttons in a column beside it, the buttons at the bottom where a thumb is, and boxes to type in high, clear of a tablet's keyboard. The root grows with the height alone. `#app.beside` sets that frame (a grid of the board's column and a side column `--beside` wide, or `--beside-cols` of a game's own) and each game places its parts in it in its own stylesheet; a game whose card divides itself (Quote's question and market) takes `#app.wide`, the whole width, and lays the halves out itself. A `.fit-half` is such a half: on a phone it isn't a box at all. A phone on its side is too short for every part, so there what doesn't fit scrolls inside the app.
- Sizes set in script (Slate's board and keys, Cartel's dice) are multiplied by `scale()` from `wide.js`, and a game that needs to know which layout is showing asks `sideways()`, whose query every stylesheet uses for its side-by-side rules (`tests/wide.mjs` checks they agree).
