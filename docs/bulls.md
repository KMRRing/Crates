# Bulls
Mastermind and Bulls and Cows (October 2026): break a hidden code from the score each guess earns. A bull is a peg of the right colour in the right place, a cow a colour the code holds but elsewhere, counted as often as both hold it (a guess of two reds against a code of one red earns one red, not two), the way Mastermind (1970) scores it and the pencil-and-paper Bulls and Cows it came from. Three ways to play alone, chosen under Play in the menu: Break (the computer hides a code, you break it), Duel (you and the computer each break the other's) and Lock (a code to reason out from clues, guessing nothing). The rules, the codemakers and the computer players are `bulls-engine.js`'s, the locks `bulls-lock.js`'s, the table for playing together `bulls-table.js`'s, all pure and tested in Node; `bulls.js` draws the board.

The boards are the genre's own: Classic, four pegs of six colours, repeats allowed, ten rows (Mastermind as sold); Super, five pegs of eight colours in twelve rows (Super Mastermind); Bulls and Cows, four different digits in ten rows, every guess four different digits too (the pencil game); and Small, three pegs of six colours in eight, a short game to learn on. Every colour carries a mark of its own (red a triangle, yellow a dot, green a square, blue a diamond, white a cross, black a star, purple a ring, orange a bar), so a colour reads by its shape too: for a colour-blind player, and in every theme. The key pegs are a peg of ink for a bull and a ring for a cow; an empty hole is a small dimple, so it never reads as a ring. Bulls draws nothing from the knowledge base: its content is colours and digits, and the menu's choices are all one-of (Play; Code, random or today's; Board; Codemaker; Computer; Level).

There is no puzzle to make in Break and none to prove: the code is drawn from the board's codes, each as likely, by a seeded generator, so a seed (a link) or a day is the same code on every device, and the code is its one answer. What makes a board hard is how many codes it has against how much a guess can tell, and that is measured by the guesses a perfect breaker needs: Knuth's minimax (1977) breaks every Classic code in five at most, 4.476 on average (5,801 guesses over the 1,296 codes, checked here code by code); Small in five, 4.05 on average; Bulls and Cows (5,040 codes) in about 5.4 on average and seven at worst, and Super (32,768 codes) in about 5.6, in samples of games (on those boards the search weighs a sample, below). The rows give room above that: ten where five will do. A single code isn't graded: picking hard codes for a hard level (AABB, say, which catch people out) would tell you something about the code before you guess. The luck in Break is in your first guesses; the Devious codemaker (Codemaker in the menu) takes it out: it hides no code at all and answers every guess with the score that keeps the most codes possible, never the win while another code still fits, so only a strategy that wins in the worst case wins (Knuth's still takes five on Classic). It never contradicts itself: the code it shows at the end fits every answer it gave.

Lock is where the making and the proving are. A lock is a code of three or four different digits and a few clue rows, each a guess and its score ("one right and in its place, one right but misplaced"), the "crack the code" puzzle of the newspapers. The generator hides a code, adds random clues while each still rules codes out, until one code is left, then drops every clue the others don't need, so each one matters; a clue that is the code itself is never dealt. Uniqueness is counted, not assumed: every code of the size (720 of three digits, 5,040 of four) is tried against the clues. Difficulty is the reasoning a person needs, measured by a solver that knows what a person writes down: which digits are in, which are out, and which digits each place can still hold. Each round it reads every clue alone against what the round before settled; when no clue alone says anything more, it reads two together, then three. The most clues read at once and the rounds it took are the grade, and the levels are made of it: Easy, three digits, each clue saying something by itself, two rounds at most; Medium, three digits, three rounds or more, or two clues read together; Hard, four digits, two clues read together; Expert, four digits, three together. Of random locks, about three in four of three digits yield to one clue at a time and one in four needs two together; of four digits, about half need two together and one in twenty three. A lock of three digits takes under a millisecond to make, of four a few; an Expert is about one lock in twenty tried (nineteen tries on average, 120 at the most before the nearest is taken), a fraction of a second on an idle computer and longer on a phone, with the rete turning meanwhile. The famous lock (682, 614, 206, 738, 780: 042) grades Medium, one clue at a time over three rounds. Hint gives the solver's next step in a person's order, the clue (or clues) that says the most first, "Clue 4: 3, 7 and 8 aren't in it.", lights it and marks its digits in the notes; a lock's score is its time and 30 seconds for each hint and each wrong code tried. Lock has no daily: today's code is the daily.

The computer plays Duel at three levels, each a breaker the engine also tests: Easy loses track of older rows (each forgotten with a chance of two in five, the latest never), as a person misreads a row, about 5.7 guesses a Classic code; Medium guesses any code that fits every row, about 4.6; Hard is Knuth's minimax, 4.476 and never more than five. Hard sometimes guesses a code that can't be the answer, because it splits the codes left better (Knuth's insight). On the big boards it weighs a sample, half codes that fit and half any, within a million scores a move: under a tenth of a second here, so a phone keeps up. In a duel you set a code for the computer (or Random), it hides one for you, and you take turns, your guess and then its, a second or so later; the fewer guesses wins and the same number is a draw (breaking its code on your fifth, it still gets its fifth). On a phone its board is the second tab over yours, your code under the shutter and its guesses at it; held sideways the two stand side by side, its guesses at your code over the controls. It stands still while the menu is open.

Today's code is Classic with the fair codemaker, the same for everyone (the suite's day), and the first visit of the day opens on it (a game under way is never cut short: the menu's Code then offers Today's first). It counts the moment it's broken or its rows run out, the first finish of the day only, in `bulls:count` (the day, and the guesses, 0 for a code not broken): the games screen's figure, "Today 4". Each board and codemaker keeps how many were played and broken and the guesses they took (an average, not a best: a best of fewest guesses is luck); each lock level its best time; each duel board and level the wins, losses and draws. The menu's About says them.

Help (Settings) is off by default. Count shows how many codes still fit what you've seen, under the shutter and after each row; Marks also marks the colours no fitting code holds as ruled out, and those every fitting code holds as in, and says when the row you've entered can't be the code. Notes are your own marks, Help or not: tap Notes, then a colour (or a digit) to rule it out, again to mark it in, again to clear it; in a lock, tap a digit where it stands in a clue. At the end of a game the codes left after each row always show, so you can see what each guess told you.

The controls are a phone's: the board of rows above (as many as the board has, so nothing moves as you play), the row being entered in large pegs under it, the colours to pick, then Notes, the back key and Guess, the plate, where a thumb is. A colour tapped fills the next empty hole; tap a peg in the row to change it, twice to take it out; tap a played row to have it back in the entry; on the digit boards a digit already in the row moves rather than repeats. On a computer, 1 to 8 pick the colours, the digits the digits, Enter guesses and Backspace takes a peg out. Nothing scrolls: the rows share the board's height, down to 22 px a row, and only Super and Bulls and Cows on the shortest phone (600 tall) scroll their rows, by a row or so, in their own box, the row being played kept in sight. The line of what to do keeps two lines of room (three in a lock), so a message never moves the board. On a tablet held upright it is all larger; held sideways the board takes the left with the height and the rows grow into it, the strip, the line, the entry, the colours and the buttons standing at the right, low. Wide or not, the rows keep a phone's width, centred, so each row's keys stay beside its pegs. The look is the instruments': the code under a brass shutter that turns its pegs over at the end, the board framed in a double rule, the pegs enamel domes; Modern, Kontor and Office have them flat and plain.

The rules (October 2026, as in every classic) are a sheet of their own, from Rules in the header or The rules in the menu, in short plain prose: the scoring with a worked example (two reds against a code holding one), the four boards, the three ways to play, how to play here (the pegs, the keys, Notes, Help, a lock's hint), the levels (a board's codes, a lock's grades), the score and today's code. It replaces the paragraph the menu folded into How it works, so the menu keeps to choices. It scrolls inside itself under its pinned head, opens at its top each time, and a lock's clock and the computer in a duel stand while it's open.

Together (October 2026), from the partner sheet or a Party of up to six, each on their own phone (`together.js`), three ways, chosen for the next game under Together in the menu (whoever deals it, with their own board or level):

- Team, the pair's first game: one board and one code for the table, anyone guessing, and the key pegs of your guess show on everyone's screen but yours ("ask Sarah", sealed on yours), so whoever guesses is always told by another what it scored. It is Crates' rule (you never see the result of your own action; your partner does): neither player can finish alone, and the one who reasons less is the one who holds the answers. A guess made on a board someone else has just guessed on is turned down, and stays in the entry to be made again on what theirs showed. Every key shows to everyone once the code is broken or the rows run out. In a lock, the clues are shared out instead: each player holds some (a table of more than four, one each, some held twice), nobody holds enough to open it alone (the clues are the fewest that open it, so any part of them leaves two codes or more, which the tests check for two to six players), the others' are sealed rows with their holder's name, and a wrong code tried costs the team 30 seconds and is told to everyone.
- Race: the same code (or lock) for everyone, each on their own board; the others' progress shows in a line under the strip (their guesses, never what they guessed). The fewest guesses wins, then the quicker, each timed from their own phone's first look at the game; a lock's race goes to the best time, hints and wrong codes at 30 seconds each.
- Versus, Break only: each sets a code for the next player round the table (two: each other's) and breaks the one set for them; the breaking starts for everyone when the last code is set, the fewest guesses wins, then the quicker. The second tab (held sideways, the side column) shows the other player breaking your code as they go.

In Team each guess carries its player's badge (their initial on their seat's colour), and at every table the strip shows who's there, yours ringed, those away greyed. Every move is a transaction made only if the table is still as the phone showed it. The end, on every phone, is the standings (`standings.js`) or the team's result, with Another game and Back to solo. The pair's record gets head-to-heads as wins each way and team games as games won of those played (a team's guesses and a lock's seconds don't compare, so no team best). The table is one `together.js` table holding all three ways rather than a race on `duel.js`: a new game for the table changes the way of playing for every phone at once, as Manifest's does, and a race of guesses needs no lobby or countdown, since guesses rank first and each player's clock runs from their own first look. The computer doesn't sit at tables: two people can always play, and it plays in Duel.

Kept on the device and synced with your solo code, all under `bulls:`: `bulls:run` (the game in play, the row being entered, the notes and the board on show, so a partner watching sees exactly your screen; a watching frame runs no clock and no computer), `bulls:prefs` (the choices), `bulls:stats`, `bulls:locks`, `bulls:duels`, `bulls:count` and `bulls:table` (the row being entered at a table, so a reload keeps it). A lock's clock runs while the page is on screen and stops with the menu, the rules and the games screen; so does the computer in a duel; a table's clock doesn't stop. Links: `#b=SEED&v=BOARD&m=MAKER` a code, `#d=DAY` a day's, `#u=SEED&v=BOARD&c=LEVEL` a duel, `#l=SEED&lv=LEVEL` a lock (Copy a link, About).

`tests/bulls.mjs` checks the scoring (repeats, symmetry, every board's count of codes), the hidden code (the same from a seed on every device, every colour as likely), today's code (the same all day, a new one each day), Knuth's tree over every Classic code (five at most, 5,801 in all) and Small's, the three levels in order and Medium's guesses always fitting, Hard on the big boards breaking every code with three rows to spare (its speed is held by the engine's budget of scores a move, so it isn't timed), the devious codemaker (consistent, as hard as the worst case, never handing over the win early), a game and a duel through to their ends and back through JSON, 115 locks across the levels (one answer counted over every code, every clue needed, none giving the code away, the grade the level asks, the hints followed settling every digit, and the work each level takes to find, in locks tried rather than seconds, which a loaded machine would stretch), the clues shared among two to six (each holds one, together all, nobody's alone enough), and tables played through the database's own round trip: Team's sealed keys and a guess turned down when another got there first, Team Lock's shared clues and strikes, a Race's standings and who it waits for, Versus's codes round the table, a new game, and a move on an old game doing nothing. In a browser, a phone played Break, Lock and a Duel through with mouse clicks and touch taps, and two phones on the stand-in database played Team, Race, Versus and Team Lock end to end.

Not done: Bulls and Cows with words (the variant guessed with four-letter words, from the suite's word list) is left out, a different game from Assay's; the computer doesn't fill a seat at a table; the games screen shows today's guesses as a plain figure, and a code not broken as 0.
