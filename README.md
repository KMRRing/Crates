# Codex

Puzzle, logic and knowledge games for the phone, alone or with a partner, online or off. It began as Crates, the first game below, and keeps that address; on the home screen it's Codex, its mark a C of brass tiers round a watch movement (README, "The mark"; the manifest, every page's home-screen title, `icon.svg`, and the PNGs, `icons/` and `icon.png`, rendered from a 3D scene).

Play: https://kmrring.github.io/Crates/ (on iPhone: Share → Add to Home Screen)

## Docs

What each game does, and the decisions behind it, is in `docs/`: one file per game or topic, named for its heading (`docs/idle.md`; a code comment that says "(README, Idle)" means that file). Read the file of the game you work on before you change it. Write to one only when Korbi has ruled on something or a trap would cost the next person time: a line or two, never a diary of changes (CLAUDE.md).

**Game names** (3 November 2026, Korbi: "for games like chess, chinese chess, guandan: no point renaming them. these aren't licensed games. for clarity, just call them by their official name unless there's a trademark issue with that (e.g. tetris)."): a game with a well-known name that is nobody's trademark wears it. Only the displayed name changed; ids, files, URLs and saved keys are still the old ones, and the old name still finds the game in the search. Old name, name now: Bulls, Conjunction (4 November 2026, Korbi: "Rename bulls"; the pencil game's bulls and cows are "aligned" and "near", and "bulls" and "mastermind" still find it) · Gambit, Chess · River, Xiangqi (Chinese chess) · Tribute, Guandan · Hong, Mahjong (Hong Kong rules) · Gammon, Backgammon · Landlord, Dou Dizhu ("Fight the landlord") · Contract, Contract bridge · Pegs, Cribbage · Meld, Gin rummy · Boast, Liar's dice · Bones, Dominoes · Silo, Four in a row (Connect Four is Hasbro's) · Flank, Reversi (Othello is a trademark) · Crown, Draughts (Checkers in the search) · Stone, Go. Kept: Rack (Scrabble), Factor (Catan), Cartel (Monopoly, Coup, Liar's Dice), Cabal (Coup), Ingot (2048), Assay, Yield, Lode (Strands), Mines (Minesweeper), and our own inventions. 3 November 2026, Korbi: "yea cut cargo fully": a falling-blocks game is cut because Tetris Holding v. Xio (2012) shows a clone's look and feel infringes, and a takedown could pull the whole app.
