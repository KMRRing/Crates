# Codex

Puzzle, logic and knowledge games for the phone, alone or with a partner, online or off. It began as Crates, the first game below, and keeps that address; on the home screen it's Codex, its mark a C of brass tiers round a watch movement (README, "The mark"; the manifest, every page's home-screen title, `icon.svg`, and the PNGs, `icons/` and `icon.png`, rendered from a 3D scene).

Play: https://kmrring.github.io/Crates/ (on iPhone: Share → Add to Home Screen)

## Docs

What each game does, and the decisions behind it, is in `docs/`: one file per game or topic, named for its heading (`docs/idle.md`; a code comment that says "(README, Idle)" means that file). Read the file of the game you work on before you change it. Write to one only when Korbi has ruled on something or a trap would cost the next person time: a line or two, never a diary of changes (CLAUDE.md).
